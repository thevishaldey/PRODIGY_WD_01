Task: Interactive Navigation Menu Web Application

This task is a part of my Web Development Internship at Prodigy InfoTech.
The assignment was to build an interactive navigation menu which sticks at the top of the page, changes its styles on scrolling, and also has hover effects on menu items.
________________________________________________________________________________________________________________________
✨ Features
- Fixed navigation bar that stays visible at the top of the page
- Background and font color change on scroll (transparent → solid gold)
- Bar shrinks in height after scrolling for a compact look
- Hover effects: background tint, color change and sliding underline
- Active link highlighting based on the section in view (scroll spy)
- Scroll progress bar along the bottom of the menu
- Smooth scrolling to sections
- Responsive design with a hamburger menu on mobile
- Keyboard-friendly focus styles and light/dark mode support
_________________________________________________________________________________________________________________________
🛠️ Technologies Used
- HTML5 → Structure
- CSS3 → Styling, Transitions and Responsive Layout
- JavaScript (ES6) → Scroll Detection, DOM Manipulation and Interactivity
_________________________________________________________________________________________________________________________
📂 Project Structure
- index.html → Structure of website
- style.css → Styling and Transitions
- script.js → Logic and Interactivity
